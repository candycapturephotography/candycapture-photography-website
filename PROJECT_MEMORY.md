## 🚀 How to Update the Website

### Step 1: Make Changes
Edit files in `C:\kiro\website\src\` folder

### Step 2: Test Locally
```bash
cd C:\kiro\website
npm run dev
```
Visit: http://localhost:3000

### Step 3: Deploy to Live
```bash
git add .
git commit -m "Your update description"
git push
```
Cloudflare automatically deploys in ~1-2 minutes!

---

## 📷 Adding New Photos

### Step 1: Add photos to the correct folder
```
C:\kiro\website\public\images\[category]\
```
Categories: `wedding`, `baby`, `maternity`, `model`, `product`, `birthday`

### Step 2: Compress large images (if over 5MB)
Create `compress-images.cjs` and run:
```bash
node compress-images.cjs
```

### Step 3: Update component to reference new images
Edit the relevant component in `src/components/`

### Step 4: Push to GitHub
```bash
git add .
git commit -m "Added new photos"
git push
```

## 🐛 Troubleshooting

### Website not updating after push?
1. Check Cloudflare Pages deployments tab
2. Look for build errors
3. Wait 2-3 minutes for deployment

### Images not loading?
1. Check file path is correct
2. Ensure images are in `public/images/` folder
3. Check image file size (max 25MB for Cloudflare)

### DNS issues?
1. Flush DNS: `ipconfig /flushdns`
2. Try different browser
3. Wait 10-30 minutes for propagation
