# Candy Capture Photography Website

Professional photography studio website for **Candy Capture Photography** based in Sivakasi, Tamil Nadu.

🌐 **Live Website:** [candycapturephotography.in](https://candycapturephotography.in)

## 📸 Services

- Wedding Photography
- Pre-Wedding Photography
- Maternity Photography
- Baby & Kids Photography
- Modeling Photography
- Product Photography
- Birthday & Event Photography
- Promotional Photography

## 🛠️ Tech Stack

- **React 19** + TypeScript
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **Lucide React** - Icons

## 🚀 Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📸 Adding New Photos

1. Add images to `public/images/[category]/`
2. Update the relevant component file
3. Run `npm run build`
4. Push to GitHub (auto-deploys to Cloudflare)
